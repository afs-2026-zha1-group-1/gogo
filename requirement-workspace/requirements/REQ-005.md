## Intent

让发起人在草稿上固定「从哪里分开、在哪里会合、最晚几点会合」：两个边界都从已确认
主线的 stop 中选取，时间直接取 stop 的排定时刻，窗口必须为正；任何非法组合在持久化
之前被拒绝，草稿回到（或保持）上一个合法状态。

## Actors and boundaries

- 编辑权限 = 草稿发起人（issue 角色 "As a split initiator"）；非发起人的成员与
  非成员被拒绝（403 / 401 契约同 REQ-004）。
- 边界归属：后端独占「stop 是否属于已确认主线」「窗口是否为正」两项判定与边界持久化；
  前端选择器只展示主线 stop 列表与窗口反馈，不自行计算合法性后直接落库。
- 时间语义：出发时刻 = 出发 stop 的 `end_at`（scheduled end），会合时刻 = 会合 stop
  的 `start_at`（scheduled start）；窗口 = 会合时刻 − 出发时刻（分钟）。
- 草稿版本联动（OQ-5 裁决）：边界成功保存属于草稿变更，`draft_version + 1`；
  被拒绝的选择不递增版本、不改动任何已保存字段。

## In scope

- 边界保存端点（`PUT /api/trips/{tripId}/split-draft/boundaries`，`X-Member-Id` 头，
  `{data,error}` 包封套）：校验草稿活跃 → 发起人身份 → 两 stop 均属已确认主线 →
  窗口为正 → 条件更新保存（携带 draft_version，防 stale）并递增版本。
- Boundary read: member-only `GET /api/trips/{tripId}/split-draft` returns main-plan
  stop options, saved boundary ids/times and `windowMinutes`; null before selection.
  No active draft returns `200 {data:null,error:null}`. See delta D1-D5-N.
- 前端边界选择屏幕（Screen 12 为呈现参考）：出发/会合选择器（选项仅主线 stop）、
  正窗口反馈、非正窗口错误态、主线外节点错误态、loading/empty/permission 态。
- 后端验收测试（正/负/越界三态 + 版本递增断言）；夹具复用 REQ-004 种子主线 v1。

## Out of scope

- 草稿发起（REQ-004 已交付）；分组路线生成（REQ-006）；窗口校验（REQ-007）。
- 自定义会合点/主线外地点创建（issue AC3 明确拒绝）；stop 时刻保持编辑（主线归 US-031/037 链）。
- 多草稿并行、草稿取消（US-050）；真实认证。
- 窗口上限/下限策略（如最小窗口阈值）：issue 只要求「正窗口」，不额外发明阈值。

## Scenarios and AC hints

| id | 场景 | 可观察结果 |
|---|---|---|
| S1 | Ben 09:00 发起草稿后，选 City Hall MRT 为出发、Merlion Park 为会合 | `200`，保存边界：出发 = City Hall MRT @ 09:30（scheduled end）、会合 = Merlion Park @ 11:30（scheduled start）、窗口 = 120 分钟；draft_version 递增 |
| S2-N | 草稿状态下选 Merlion Park 出发（scheduled end 12:00）、City Hall MRT 会合（scheduled start 09:00） | `400` 且 `code = NONPOSITIVE_SPLIT_WINDOW`；已保存边界不变，draft_version 不变 |
| S3-N | 选 Singapore Zoo（不在已确认主线 stop 中）为任一边界 | `400` 且 `code = BOUNDARY_NOT_IN_MAIN_PLAN`；不创建无关会合点，已保存边界不变 |
| S4-N | 非发起人成员尝试保存边界 | `403` 且 `code = NOT_SPLIT_INITIATOR`；边界不变 |
| S5-N | 无活跃草稿时保存边界 | `409` 且 `code = SPLIT_DRAFT_NOT_ACTIVE`；无持久化 |
| S6-N | 携带过期 draft_version 的保存请求 | `409` 且 `code = STALE_DRAFT_VERSION`；当前边界不变 |

错误码为稳定机器可读契约；message 为实现文本。S2-N 的「已保存边界不变」包含
「此前从未保存过边界则仍为空」的情形。

## Constraints

- 同 REQ-004 全部技术约束（JdbcClient 无 ORM、SQLite 三铁律、Flyway 独占、
  `{data,error}` 包封套、`X-Member-Id`、时间 TEXT ISO-8601 UTC）。
- 边界不新建表、不加列：存于 `trip.split_draft` JSON 文档的边界字段
  （字段明细见 deep-dive B 链段）；stop 引用 `plan_node.id`，不复制地点数据。
- 窗口计算以分钟为粒度，夹具语境 Asia/Singapore (+08:00)；存储值为 UTC，
  展示换算由前端按行程时区处理（P3 细化）。
- 前端增量引入新栈，greeting 页保持 JSX（用户 2026-11-15 裁决，同 REQ-004）。

## Affected capabilities

能力 `splits` 新增 requirement：**Split boundary selection**
（主线内 stop 选择、scheduled end/start 时间语义、正窗口强制与非法拒绝）。
