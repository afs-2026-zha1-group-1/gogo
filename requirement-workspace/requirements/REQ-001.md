## Intent

Minimal vertical slice through the full stack. The greeting text must originate
from persisted data so that the database link is genuinely exercised.

## Actors and boundaries

- Visitor: reads the home page. No input, no session, no permissions.
- Backend: owns the `greeting` table and the read endpoint.
- Frontend: owns rendering only; it must not contain the literal greeting.

## In scope

- `greeting` table with one seeded row, created by a database migration.
- `GET /api/greeting` returning the stored message.
- React home page fetching and rendering that message.
- Embedded file-mode database (H2 per source 2), no separate DB service.
- GitHub Actions workflow building and testing both apps (source 3, harness).

## Out of scope

From `TODO.md` non-goals: multi-language or configurable greeting management UI,
user accounts, permissions, ORM. Additionally out of scope for this change:
production deployment, CD trigger, authentication on the endpoint, and any
greeting write/update API.

## Scenarios and AC hints

| id | Scenario | Observable outcome |
|---|---|---|
| AC1 | Start the backend with no database file present | A database file appears and contains exactly one `greeting` row whose message is `Hello World` |
| AC2 | `GET /api/greeting` | HTTP 200 with body `Hello World` |
| AC3 | Open the home page with the backend running | The page shows `Hello World`, and the text came from the endpoint (frontend source contains no literal greeting) |
| AC3-N | Open the home page with the backend stopped | The page shows a load-failure message instead of a greeting or a blank page |

AC3-N is a reverse case for the "no hard-coded text" constraint: a hard-coded
frontend would still show `Hello World` when the backend is down.

## Constraints

- React frontend, Spring Boot / Java backend (`TODO.md` lines 19–21).
- Embedded database, no standalone DB service. Engine: H2 file mode (source 2
  supersedes SQLite).
- Flyway migration per `TODO.md` line 21 — see OQ-2 for the contradiction with
  the non-goal line.
- No ORM (non-goal, `TODO.md` line 33).
- Repository documentation in English (`AGENTS.md`).
