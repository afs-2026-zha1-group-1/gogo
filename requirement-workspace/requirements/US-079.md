## Intent

把"地图导航"从演示拐棍（前端写死地址簿 + 名字搜索链接）升级为正经能力：地址/坐标随方案落库、
地址簿以缓存表形式跨行程沉淀、导航以坐标直链在新标签页打开完整高德页面；嵌入形态整体废除。
P2 delta-craft / G1 待用户确认。

## In scope

1. **导航入口**：站点卡片右侧薄荷绿"高德"按钮（真 `<a target="_blank">`）；倒计时卡"下一站"地址行同款按钮。无 iframe 嵌入。
2. **路线直链**：`https://www.amap.com/dir?from[name]/from[lnglat]/to[name]/to[lnglat]`；坐标经 WGS-84→GCJ-02 纠偏（国内加偏、港澳/海外不偏）；起点=上一活动站，首站只带终点、起点留空手填。
3. **兜底链**：站点落库坐标 → 前端地址簿（place-book.ts）→ 高德电脑版搜索页直链（`www.amap.com/search?query=站名+城市`，目的地自动带出、起点手填）。不经 uri.amap.com（UA 跳手机版纯壳）。
4. **地址展示/复制**：倒计时卡"下一站"地址行（保存地址 → 地址簿），复制按钮 + 失败就地提示；无地址显示"地址待确认"。
5. **落库与沉淀（路线1）**：V10 给 `main_plan_stop` 加 address/lat/lng 可空列；新建 `place_cache(name,city PK, address, lat, lng, source)` 种子 19 站；生成落库时查缓存补全；新端点 `POST /api/trips/{id}/main-plan/stop-locations` 回写程序查的坐标并 upsert 缓存（source=geocode）；读方案每站带三字段（null 省略）；确认投影把坐标抄进 `plan_node` 预留列。
6. **程序查坐标**：生成后前端对"无坐标且有地址"的站调高德 JS API Geocoder（JS Key+安全密钥，.env 注入），多结果取第一个、8s 超时、失败留空；海外查不到留空走兜底。
7. **语义图标**：站点图标按名称关键词（渡轮/展馆/山峰/市集）→ 兴趣标签（food/coffee/nature/heritage/craft/photo/slow）→ 公园花园 → 兜底 pin/route；新增 7 个线条图标。
8. **演示回填能力**：demo-seed.py 三列回填（本次只改未跑，保护已确认方案）。
