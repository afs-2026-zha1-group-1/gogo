## 原始意图（issue #141 摘要）

作为行程成员，我希望从行程中的具体站点打开高德地图，并将该站点设为目的地、我的当前位置设为出发地，
以便直接导航到要去的地点。验收含：无主线不显示按钮；主线生成后逐站有按钮；分队确认后个人路线逐站有按钮；
不同站点不串目的地；地址与会合说明可复制；地图不可用时行程仍可查看、缺失信息标待确认。

## 用户裁决（2026-11-18，按时间序）

1. 废除嵌入弹窗方案："不使用当前的嵌入方式，直接新开一个界面显示导航，返回就返回到上一级行程"。
   依据实测：电脑版登录面板比弹窗宽被裁；手机版搜索页是纯壳不认搜索词；嵌内规划路线必触发高德登录墙。
2. 出发地口径：系统定位不可用（本机 Windows 定位总开关 Deny，疑似公司策略）→ **起点=上一活动站地址/坐标**；
   **首站无上一站 → 起点留空由用户手填**。
3. 坐标不由 AI 输出（"AI 找不出来"）→ **程序补坐标**：地址簿缓存种子 + 生成后浏览器 JS API 地理编码回写存库。
4. 地址簿要"会长大"：落库进 `place_cache`（种子/程序查/人工补三来源），跨行程复用；前端写死地址簿降为兜底。
5. 高德路线页**只认坐标不认名字**（登录也不认，实测）→ 路线直链必须带 lnglat；国内点 WGS-84→GCJ-02 纠偏。
6. Key 口径：用户提供的 JS Key + 安全密钥用于浏览器侧地理编码回写（.env，不入库）；
   REST 地理编码需 Web-service Key（实测 JS Key 报 USERKEY_PLAT_NOMATCH），本轮不启用。
7. UI：站点卡片右侧薄荷绿"高德"小按钮；地址与复制放倒计时卡"下一站"行；站点图标按名称/兴趣标签语义化。
8. 海外地址高德查不了 → 留空走兜底（地址簿/搜索页），不造假坐标；全自动覆盖海外另立项。
