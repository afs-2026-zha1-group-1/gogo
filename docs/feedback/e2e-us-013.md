# E2E checklist — US-013 Screen 7

- Change: `us-013-view-trip-members`
- Environment: backend on `http://localhost:8080` (seeded `V2` data), Vite dev
  server on `http://localhost:5173`, hash router.
- Fixture trip: `Singapore Friends Day` (Alice 1 organizer; Ben 2, Chloe 3,
  Daniel 4 members; Eve 5 outsider).
- Acceptance criteria and fixtures govern; this checklist is the browser layer
  of the ATDD design. Screenshots are not required.

## Preconditions

1. Backend running from the current branch code (contains
   `GET /api/trips/{id}/members`).
2. Frontend dev server running from the current branch code.
3. Identity switcher visible and labeled as a scaffold (非登录).
4. Open the trip details with a known trip id, e.g. `#/trips/1`.

## U1 — Member roster and organizer

1. From the details page, activate the 成员 tab.
2. Observe the page heading 成员 and a member count.
3. Observe four rows: Alice, Ben, Chloe, Daniel, each once.
4. Observe the 组织者 pill on Alice only; no readiness ring, readiness pill,
   preference summary, budget line or 生成主线方案 action.
5. Observe the hint that the page shows members only.

Expected: all four members, Alice identified as organizer, no planning data.

## U2 — Identity switch and denial

1. On the 成员 page, switch the scaffold identity to Eve.
2. Observe the permission-denied state: no member names, no organizer value.
3. Switch back to Ben.
4. Observe the four-row roster returns.

Expected: outsider denied without identities; member restored.

## U3 — No trip selected

1. Open a fresh tab at `#/members` without opening a trip first (or reload the
   page on `#/members`).
2. Observe the no-trip guidance state with a link back to 行程.
3. Observe no fabricated member rows.

Expected: guidance only; no demo data.

## States

| State | How to reach | Expected |
|---|---|---|
| Loading | Open 成员 with a throttled network / immediate render | Loading text; no stale rows |
| Permission denied | U2 (Eve) | Denied card; no names |
| Error | Stop the backend, open 成员, retry after restart | Generic failure + 重试; no private data |
| Missing trip | Not reachable from `#/members` (the route carries no trip id); API M6 covers 404 `TRIP_NOT_FOUND` | UI implements the state; verify by code inspection |
| Empty roster | Not reachable through product writes (organizer is inserted atomically); UI implements the state | Empty card; no fabricated rows |

## Shell regression

1. Visit 仪表盘 → 行程 → 分队 → 成员 and back.
2. Each tab shows its own page; 分队 remains the honest placeholder; 成员 shows
   the roster or its guidance state.
3. Identity selection persists across tab switches.
