## UI 对齐说明（2026-11-17）

首轮注册页沿用了登录页的 hero + card 结构，与用户提供的移动参考稿不一致。已在
P4 中按参考稿重做：顶部返回 + “创建 GoGo 账号”、品牌头部、名字/邮箱/密码/确认
密码、密码提示“至少 8 个字符”、主/次按钮；浏览器截图复核一致。API 契约保持
G1 批准的 6–72 字节；前端更严格（≥8 字符 + 确认一致）。

My Account 同样按第二张参考稿重做：顶部返回 + “我的”、头像首字母 + 名字 +
邮箱、名字输入、“保存名字”主按钮、红色描边“退出登录”；移除旧的分区标题与
卡片。浏览器面板此时不可见，改用 snapshot + computed style 核对结构/颜色，
保存与退出交互均通过。底部 dock 同步改为五列，确保五个 tab 不换行。

重复邮箱注册原先静默跳登录页、没有任何反馈。用户 2026-11-17 明确要求改为注册时
直接弹窗：新邮箱弹“注册成功”，重复邮箱弹“该邮箱已注册”，两种都提供“去登录”
（重复另给“修改邮箱”）。该指令覆盖 US-070 原“不披露邮箱是否已注册”的隐私
AC；服务端重复邮箱改为 `409 EMAIL_TAKEN`，接受邮箱枚举风险，已记录在 G1 addendum。
